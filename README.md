# Eurojackpot

A simple **C# implementation of a Eurojackpot lottery simulation**, developed as part of university laboratory exercises.

The project was created primarily for educational purposes and focuses on practicing C# programming, object-oriented programming and automated testing.

## Project Overview

The application simulates the basic mechanics of the Eurojackpot game by generating lottery numbers according to the game's rules.

The project also includes a separate test project used to verify the application's behavior.

## Technologies

* **C#**
* **.NET**
* **Unit testing**
* **Object-oriented programming**

## Project Structure

```text
Eurojackpot/
├── Eurojackpot/          # Main application
├── GraEurojackpot.test/  # Automated tests
└── .gitignore
```

## Features

* Eurojackpot number generation
* Simulation of a lottery draw
* Separation of application logic and tests
* Automated verification of application behavior

## Testing

The project contains a dedicated test project:

`GraEurojackpot.test`

The tests are intended to verify the correctness of the lottery simulation and its underlying logic.

Keeping the application and tests in separate projects also reflects the basic separation between production code and test code.

## Purpose

This project was created as part of university laboratory exercises and should be considered an **educational project rather than a production-ready lottery application**.

Its main purpose was to practice:

* C# programming
* object-oriented programming
* working with .NET projects
* designing application logic
* writing automated tests

## Disclaimer

This project is a programming exercise and is **not affiliated with the official Eurojackpot lottery**.

It is intended for educational purposes only.
